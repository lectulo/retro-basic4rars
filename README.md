# Интерпретатор BASIC для RARS

Интерпретатор для выполнения учебных программ в RARS 1.6. Реализован диалект
Minimal BASIC с расширениями и отдельными ограничениями: числовые и строковые
переменные, массивы, циклы, подпрограммы, функции и консольный ввод-вывод.

## Сборка

Необходимы CMake, компилятор C, Clang с поддержкой RISC-V, AWK, Java и RARS 1.6.
Команды выполняются из корня репозитория. Вместо `/path/to/rars1_6.jar`
укажите абсолютный путь к файлу симулятора.

```sh
cmake -S . -B build -DRARS_JAR=/path/to/rars1_6.jar
cmake --build build -j 4
```

При сборке исходники на C99 кросс-компилируются в RV32IMF, затем ассемблер
адаптируется для RARS. Результат — все файлы `.s` в `build/rars/basic/`.
Они составляют единый комплект и должны храниться вместе. Файлы `.gas`
являются промежуточными и для запуска не нужны.

Для сборки только ассемблерного комплекта:

```sh
cmake --build build --target asm_basic -j 4
```

## Запуск в RARS

```sh
java -jar /path/to/rars1_6.jar nc me sm we se1 ae2 \
  20000000 build/rars/basic/*.s pa test/progs/demo_func_table.bas
```

После `pa` указан путь к программе BASIC. Этот путь должен состоять из
символов ASCII. Команда рассчитана на оболочку, раскрывающую `*.s`.
Число `20000000` ограничивает количество шагов симуляции; для длительных
программ его можно увеличить.

В графическом RARS откройте `build/rars/basic/port_rars.s`. В Settings включите:

- `Assemble all files in directory`;
- `Initialize Program Counter to global 'main' if defined`;
- `Program arguments provided to program`;
- `Permit extended (pseudo) instructions and formats`.

Режим `64 bit` должен быть выключен. Нажмите F3. В поле Program Arguments
вкладки Execute укажите абсолютный путь к файлу BASIC, затем нажмите F5.
Результаты и приглашения INPUT появятся в Run I/O.

## Примеры и проверки

В `test/progs/` находятся шесть демонстраций: квадратное уравнение, таблица
функции, сортировка, интегрирование, игра и обработка текста. Файлы `.expected`
задают ожидаемый вывод, `.in` — подготовленный ввод, если он требуется.

```sh
ctest --test-dir build --output-on-failure
```

Комплект включает 14 проверок: один модульный тест и шесть демонстраций
для каждой из двух сред — хостовой и RARS. Для запуска только проверок RARS:

```sh
ctest --test-dir build --output-on-failure -R rars
```

Ожидаются семь проверок RARS. Хостовая версия используется для отладки:

```sh
./build/basic test/progs/demo_func_table.bas
```

В `test/nbs/` сохранены 208 программ National Bureau of Standards
«Minimal BASIC Test Programs, Version 2». Происхождение описано в
[test/nbs/NOTICE.md](test/nbs/NOTICE.md). Эти программы можно запускать отдельно;
некоторые намеренно содержат ошибки. Они не входят в указанные 14 проверок.
Полное прохождение NBS и полное соответствие стандарту не заявляются.

Спецификация языка и руководство оператора входят в комплект документации
курсового проекта.
