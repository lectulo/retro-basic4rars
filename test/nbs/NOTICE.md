# Происхождение

208 программ `P001.BAS`–`P208.BAS` и `README.NBS` — набор National Bureau of
Standards «Minimal BASIC Test Programs, Version 2», продукт федерального
агентства США и общественное достояние. Часть тестов (список — в шапке
`README.NBS`) предоставил Эммануэль Рош, остальные перенабраны с PDF Google
Books.

Источник копии — репозиторий компилятора John Gatewood Ham
(https://sourceforge.net/projects/buraphakit/, клон
`git://git.code.sf.net/p/buraphakit/MB_git`). Сам компилятор лицензирован
GPLv2 и в этот репозиторий не переносился — взят только каталог `NBS/`,
который в README проекта отдельно назван общественным достоянием.
